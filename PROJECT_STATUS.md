# Статус проекта: Калькулятор билетов TETYS BLUE (Сезон 2026)

Этот файл содержит историю последних изменений и план дальнейших работ по проекту. Он поможет быстро сориентироваться при переносе проекта на другой ПК.

## ✅ Что уже сделано (Последние изменения)

### 1. Архитектура и UI (Интерфейс)
* **Двухколоночный дизайн (Dashboard):** Интерфейс разделен на левую колонку ("Параметры посещения") и правую ("Список посетителей"). Это решило проблему мобильной версии, где меню было слишком сжатым.
* **Вкладка "Быстрый расчет":** Добавлена вкладка для моментального расчета стоимости без ввода ФИО и дат рождения гостей (ADL, CHLD, PENS, INF).
* **Модальные окна:** Реализовано чистое модальное окно поверх экрана для установки индивидуальных цен.

### 2. Бизнес-логика и Расчеты
* **Ручная корректировка цен:** Возле стоимости билета для каждого гостя добавлена иконка "Карандаш" (✏️). При клике открывается окно, позволяющее менеджеру установить индивидуальную цену, которая пойдет в итоговый чек.
* **Раннее бронирование (Скидка 15%):**
  * Добавлен переключатель (тумблер), который появляется при выборе дат визита с 1 по 23 августа.
  * Убрана жесткая привязка к часам, чтобы избежать багов из-за неправильных часовых поясов на устройствах менеджеров.
  * Исправлен баг "залипания" нерабочей акции путем обновления Service Worker.
* **Расчет прибыли (Маржинальность):** В объект тарифов `CONFIG.tariffs` внедрен параметр `net` (себестоимость). Система теперь корректно учитывает разницу между ценой продажи (Турист/Агент) и себестоимостью для расчета чистой прибыли.

### 3. Техническая часть
* **Обновление Service Worker (sw.js):** 
  * Версия кэша повышена до `tetys-calc-v4`. 
  * Добавлены команды `self.skipWaiting()` и `self.clients.claim()`.
* **Улучшение PWA:** Добавлены уведомления для менеджеров о том, что "Приложение обновлено до новой версии".
* **Автосохранение черновика:** Приложение автоматически сохраняет черновики в `localStorage` (ключ `tetisBluDraft`).
* **Масштабный рефакторинг кода:** Логика успешно разделена на логические модули: `config.js`, `pricing.js`, `utils.js` и `main.js`. Код приведен в порядок и готов к масштабированию.

### 4. Интеграция с БД и Автоматизация (Supabase + Make.com)
* **Подключение Supabase:** Настроена синхронизация чеков/заказов и аналитика для менеджеров через централизованную базу данных.
* **Автопилот Ваучеров:** Приложение теперь автоматически зажигает зеленую иконку 🎫 ("Ваучер готов") возле заявки, как только Make.com обрабатывает PDF-ваучер от аквапарка. (Осталась только настройка переадресации на стороне почты).
* **Автоматическая сверка с банком:** Написан функционал, который загружает выписку из банка (Excel), сопоставляет суммы и автоматически массово переводит найденные заявки в статус "Оплачено" в базе данных.
