# Установка парсера ваучеров в Gmail

Этот скрипт позволит вашей почте автоматически находить ваучеры и отметки об отмене, а затем напрямую связываться с вашей базой Supabase для обновления статуса `voucher_status`.

## Шаг 1: Открытие редактора скриптов
1. Зайдите в браузер под Google-аккаунтом администратора (на чью почту приходят ваучеры).
2. Перейдите по ссылке: [script.google.com](https://script.google.com/)
3. Нажмите кнопку **«Новый проект»** (New Project) в левом верхнем углу.

## Шаг 2: Вставка кода
1. Перед вами откроется редактор кода с названием файла `Код.gs`.
2. Удалите всё, что там написано по умолчанию (`function myFunction() { ... }`).
3. Скопируйте весь код из подготовленного мной файла [gmail_voucher_parser.gs](file:///C:/Users/rusta/.gemini/antigravity-ide/brain/a12c5b4f-6496-471c-a7b8-404842072ec3/gmail_voucher_parser.gs) и вставьте в редактор.
4. Нажмите иконку **дискеты** (или `Ctrl + S`), чтобы сохранить. Сверху предложит ввести название проекта — назовите его, например, «Парсер Ваучеров».

> [!WARNING]
> Обязательно проверьте константу `SEARCH_QUERY` на 8 строке скрипта. Вам нужно вписать туда реальный email адрес аквапарка (например, `from:booking@aquapark.ru is:unread`).

## Шаг 3: Настройка регулярных выражений (Поиск Имени и Даты)
Так как вы сказали, что ваучеры приходят в формате PDF, но нужная информация может дублироваться в тексте или теме, вам нужно будет посмотреть на 1-2 реальных письма.
В функции `extractDataFromEmail` есть блоки поиска имени и даты. Если стандартный поиск не будет срабатывать, нужно будет чуть-чуть подкорректировать там слова (например, искать после слова "Пассажир:", а не "Гость:"). 

*Если нужно парсить именно внутри PDF, Google Apps Script умеет конвертировать PDF в текст, но это требует немного другого кода. Давайте пока попробуем найти инфу в тексте письма!*

## Шаг 4: Тестирование и Авторизация
1. Вверху редактора (рядом с кнопкой Выполнить) выберите функцию `processNewVouchers`.
2. Нажмите кнопку **Выполнить** (Run).
3. Google попросит предоставить разрешения (Authorization required). 
4. Нажмите **Review permissions**, выберите аккаунт админа. Появится предупреждение «Google hasn’t verified this app». Нажмите **Advanced** (Дополнительные настройки) и внизу выберите **Go to Парсер Ваучеров (unsafe)**. Разрешите доступ к чтению почты и выполнению внешних запросов.
5. Посмотрите в лог выполнения (внизу). Там будет написано, нашел ли скрипт письма и попытался ли обновить Supabase.

## Шаг 5: Настройка расписания (Триггер)
Чтобы скрипт работал сам по себе 24/7, настроим ему расписание:
1. В левом меню нажмите на иконку **часов** («Триггеры»).
2. В правом нижнем углу нажмите синюю кнопку **«Добавление триггера»** (Add Trigger).
3. Настройте параметры:
   - Выберите функцию: `processNewVouchers`
   - Выберите источник события: `Триггер по времени` (Time-driven)
   - Выберите тип триггера: `По минутам` (Minutes timer)
   - Выберите интервал: `Раз в 5 минут` (Every 5 minutes)
4. Нажмите **Сохранить**.

> [!TIP]
> Готово! Теперь почта сама будет проверять папку входящих каждые 5 минут. Письма, которые скрипт успешно обработает, он пометит как **прочитанные**, чтобы не дергать базу данных дважды.
