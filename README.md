# Tetys Blu — Умный калькулятор тарифов 🌊

Веб-приложение для мгновенного расчета стоимости посещения комплекса Tetys Blu. Разработано для автоматизации работы кассиров и менеджеров: позволяет в один клик превращать сырой текст из WhatsApp или CRM в готовый, математически точный расчет.

## 🚀 Главные функции (Особенности)

- **🤖 Умный парсинг текста (Smart Bulk Input):** Менеджеру достаточно вставить скопированный список гостей (например, "Иванов Иван 25.08.1990, Анна 5 лет"). Система автоматически распознает даты рождения, возраст и имена, раскидав их по нужным категориям.
- **🧮 Сложная бизнес-логика скидок:** 
  - Автоматическое определение младенцев (до 3 лет) — бесплатно.
  - Определение детского и взрослого тарифа.
  - Расчет пенсионного возраста (с учетом гендера и законов РК).
  - Учет именинников (скидка 50% в день рождения).
  - Скидки по инвалидности (I, II, III группы).
- **⏱ Акции с жесткой привязкой ко времени:** Реализована акция "Раннее бронирование", которая автоматически появляется в интерфейсе только в строго заданные даты (например, 28-30 июня) при выборе визита на июль.
- **🧾 Генерация нередактируемых чеков:** Для безопасности расчетов приложение "фотографирует" итоговый расчет и формирует `.png` картинку чека. Клиент получает красивый файл, в котором невозможно подделать итоговую сумму.
- **📲 Нативная интеграция Share API:** Отправка чеков напрямую через системное меню смартфонов (iOS/Android) в любые мессенджеры.
- **📱 PWA (Progressive Web App):** Приложение можно установить на рабочий стол телефона или компьютера как полноценную программу, работающую без адресной строки браузера.

## 🛠 Технологии

- **HTML5 / Структура:** Семантическая разметка.
- **Tailwind CSS:** Использован для создания современного, отзывчивого (Responsive) и "чистого" интерфейса. UI адаптирован как под широкие экраны касс, так и под мобильные устройства менеджеров.
- **Vanilla JavaScript (ES6+):** Вся сложная логика расчетов, парсинга регулярными выражениями и работы с датами написана на чистом JS без тяжелых фреймворков для максимальной скорости работы.
- **html2canvas:** Библиотека для рендеринга DOM-элементов в Canvas (для генерации красивых картинок-чеков).

## 📥 Установка и запуск

Проект не требует сборки (No build step). 
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/tetis-blue-calc.git
   ```
2. Откройте файл `index.html` в любом современном браузере.
3. Для публикации в интернете достаточно загрузить файлы на любой статический хостинг (Vercel, GitHub Pages, Netlify).
